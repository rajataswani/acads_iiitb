Q2. Multiple Linear Regression
Tier 3

A house-price model uses two features: area \(x_1\) and number of bedrooms \(x_2\).

\[\hat y=w_0+w_1x_1+w_2x_2\]
\[X=\begin{bmatrix}1&1&2\\1&2&2\\1&3&3\end{bmatrix},\qquad y=\begin{bmatrix}4\\7\\10\end{bmatrix}\]
  1. Explain what each column of \(X\) represents.
  2. Calculate \(X^TX\) and \(X^Ty\).
  3. Obtain \(w^*\).
  4. Calculate the prediction for \(x_1=4,x_2=3\).

Solution

  1. The first column contains 1s for the intercept \(w_0\). The second column contains area \(x_1\), and the third contains bedrooms \(x_2\).
  2. Multiply the matrices:
    \[X^TX=\begin{bmatrix}3&6&7\\6&14&15\\7&15&17\end{bmatrix},\qquad X^Ty=\begin{bmatrix}21\\48\\52\end{bmatrix}.\]
  3. Using \(w^*=(X^TX)^{-1}X^Ty\), we get
    \[\boxed{w^*=\begin{bmatrix}1\\3\\0\end{bmatrix}}.\]
  4. Hence
    \[\hat y=1+3x_1.\]
    For \(x_1=4,x_2=3\),
    \[\hat y=1+3(4)+0(3)=\boxed{13}.\]

Q3. Regression Error
Tier 3
\(y\)\(\hat y\)

Calculate (1) every residual, (2) RSS, (3) MSE, and (4) explain whether MSE or RSS changes if the number of observations changes while all errors remain the same.

Solution

The residual is actual minus predicted:

\[e_i=y_i-\hat y_i.\]

The four residuals are \(2,-1,2,1\).

RSS is the sum of squared residuals:

\[RSS=2^2+(-1)^2+2^2+1^2=4+1+4+1=\boxed{10}.\]

MSE is RSS divided by the number of observations \(n=4\):

\[MSE=\frac{RSS}{n}=\frac{10}{4}=\boxed{2.5}.\]

If the number of observations changes while the same error values are repeated/maintained, RSS grows with the number of terms, whereas MSE averages those errors and therefore stays tied to the average squared error.

Given \(x=[1,2,3]\) and \(\hat y=w_0+w_1x+w_2x^2\):

  1. Construct \(X\).
  2. Explain why this is still a linear regression model even though \(x^2\) appears.
  3. Write the closed-form solution for \(w^*\).
  4. Explain what happens to model flexibility when degree is increased from 2 to 6.

Solution

  1. Because the model contains \(1,x,x^2\),
    \[X=\begin{bmatrix}1&1&1\\1&2&4\\1&3&9\end{bmatrix}.\]

    \[\boxed{w^*=(X^TX)^{-1}X^Ty}.\]

Part C — Bias–Variance

Q7. Bias–Variance Decomposition
Tier 3

A model has \(Bias^2=4\), \(Variance=9\), and \(Noise=2\). Calculate the expected generalization error using the bias–variance decomposition. Then explain what happens if model complexity is increased.

Solution

Use the decomposition

\[E[(y-\hat f(x))^2]=Bias^2+Variance+Noise.\]

Here the values are 4, 9, and 2:

\[4+9+2=\boxed{15}.\]

When model complexity increases, bias generally decreases because the model can fit more complicated patterns, but variance generally increases because the model becomes more sensitive to the training sample. The goal is not maximum complexity; it is a good balance that gives low generalization error.

Part D — Cross Validation

Q10. 5-Fold CV
Tier 3

A model is evaluated using 5-fold cross-validation. Validation MSEs are \(4,6,5,7,3\). Calculate the 5-fold CV error.

Solution

For K-fold cross-validation, average the validation errors from all folds:

\[CV\ Error=\frac{4+6+5+7+3}{5}=\frac{25}{5}=\boxed{5}.\]

Thus the estimated 5-fold CV MSE is 5.

Calculate the Ridge solution

Solution

For Ridge regression, add \(\lambda I\) to \(X^TX\):

\[w^*=\frac1{29}\begin{bmatrix}5&-1\\-1&6\end{bmatrix}\begin{bmatrix}10\\8\end{bmatrix}=\frac1{29}\begin{bmatrix}42\\38\end{bmatrix}.\]
\[\boxed{w^*=\begin{bmatrix}42/29\\38/29\end{bmatrix}\approx\begin{bmatrix}1.448\\1.310\end{bmatrix}}.\]
Q14. L1 vs L2
Tier 2

Suppose an unregularized model produces \(w=[5,-3,0.5,0.01]\). Explain qualitatively what you expect under (1) L1 regularization and (2) L2 regularization. What happens when \(\lambda\) is increased?

Solution

L1 regularization (Lasso) adds a penalty proportional to the sum of absolute coefficient values:

\[L_{L1}=L+\lambda\sum_j|w_j|.\]

It encourages sparsity, so some coefficients can become exactly zero. With the given vector, small coefficients such as 0.01 are especially likely to be driven to zero as \(\lambda\) becomes stronger.

L2 regularization (Ridge) uses squared coefficients:

\[L_{L2}=L+\lambda\sum_jw_j^2.\]

It shrinks coefficients toward zero, but generally does not make them exactly zero.

Increasing \(\lambda\) strengthens the penalty: L1 tends to produce more zero coefficients; L2 tends to shrink coefficients more strongly.

Q15. Regularization Penalty
Tier 2

Two models have \(w_A=[10,8,7,6]\) and \(w_B=[2,1.5,0.5,0.1]\). Both have approximately the same training error. Which model would regularization prefer and why? Calculate the L2 penalty \(\sum_jw_j^2\) for both.

Solution

When training errors are approximately equal, regularization prefers the model with smaller parameter magnitudes because its penalty is smaller.

For model A:

\[\sum_jw_j^2=10^2+8^2+7^2+6^2=100+64+49+36=\boxed{249}.\]

For model B:

\[\sum_jw_j^2=2^2+1.5^2+0.5^2+0.1^2=4+2.25+0.25+0.01=\boxed{6.51}.\]

Therefore regularization strongly prefers Model B because it has much smaller coefficient magnitude and hence a much smaller L2 penalty.

Part F — Maximum Likelihood Estimation (MLE)

Q16. Gaussian MLE
Tier 2

Predictions are \(\hat y=[10,12,15,20]\), actual values are \(y=[11,10,16,18]\), and \(\epsilon_i\sim N(0,\sigma^2)\). Calculate

\[\sigma^{2*}=\frac1n\sum_i(y_i-\hat y_i)^2.\]

Solution

First compute the errors:

\[y-\hat y=[11-10,\;10-12,\;16-15,\;18-20]=[1,-2,1,-2].\]

Square them:

\[1^2+(-2)^2+1^2+(-2)^2=1+4+1+4=10.\]

There are \(n=4\) observations, so the MLE of the noise variance is

\[\sigma^{2*}=\frac{10}{4}=\boxed{2.5}.\]
Q17. Likelihood
Tier 2

Three independent observations have likelihoods \(0.8,0.6,0.9\). (1) Calculate the whole-data likelihood. (2) Write the log-likelihood. (3) Explain why log-likelihood is preferred computationally.

Solution

  1. Because the observations are independent, multiply their likelihoods:
    \[L=0.8\times0.6\times0.9=\boxed{0.432}.\]
  2. The log-likelihood is
    \[\log L=\log(0.8)+\log(0.6)+\log(0.9)\approx\boxed{-0.8393}.\]
  3. Log-likelihood is preferred because a product of many small probabilities can become numerically tiny. Taking logs converts the product into a sum and makes differentiation and optimization easier, while preserving the maximizing parameter because log is monotonic.
Q18. MLE + Least Squares
Tier 2

Given \(y_i=f(x_i;w)+\epsilon_i\) and \(\epsilon_i\sim N(0,\sigma^2)\), explain mathematically why maximizing Gaussian likelihood with respect to \(w\) is equivalent to minimizing \(\sum_i(y_i-f(x_i;w))^2\). You do not need the complete matrix derivation; identify the important term in the log-likelihood.

Solution

Under Gaussian noise, the log-likelihood has the form

\[\log L=-\frac n2\log(2\pi)-n\log\sigma-\frac{1}{2\sigma^2}\sum_i\bigl(y_i-f(x_i;w)\bigr)^2.\]

When maximizing with respect to \(w\), the first two terms do not depend on \(w\). The only \(w\)-dependent part is

\[-\frac{1}{2\sigma^2}\sum_i\bigl(y_i-f(x_i;w)\bigr)^2.\]

Maximizing this is exactly the same as minimizing the positive squared-error sum:

\[\boxed{\sum_i\bigl(y_i-f(x_i;w)\bigr)^2}.\]

Hence, Gaussian MLE with respect to \(w\) gives the same parameter estimate as least-squares minimization.

Part G — Bayesian Approach

Q19. Bayesian Posterior
Tier 3

Given \(P(D|\theta)=0.8\), \(P(\theta)=0.3\), and \(P(D)=0.5\), calculate \(P(\theta|D)\) using Bayes' theorem.

Solution

Bayes' theorem is

\[P(\theta|D)=\frac{P(D|\theta)P(\theta)}{P(D)}.\]

Substitute the given values:

\[P(\theta|D)=\frac{0.8\times0.3}{0.5}=\frac{0.24}{0.5}=\boxed{0.48}.\]

So after observing the data, the posterior probability of \(\theta\) is 0.48.

Q20. Posterior Comparison
Tier 3

Two possible models have \(P(D|\theta_1)=0.7,P(\theta_1)=0.4\) and \(P(D|\theta_2)=0.5,P(\theta_2)=0.6\). Compare their posterior probabilities. You may use proportionality instead of calculating \(P(D)\).

Solution

Using proportionality,

\[P(\theta|D)\propto P(D|\theta)P(\theta).\]

Calculate the unnormalized posterior scores:

\[\theta_1:\;0.7(0.4)=0.28,\qquad \theta_2:\;0.5(0.6)=0.30.\]

Thus \(\theta_2\) has the larger posterior. If normalized,

\[P(\theta_1|D)=\frac{0.28}{0.58}\approx0.483,\qquad P(\theta_2|D)=\frac{0.30}{0.58}\approx0.517.\]

Q21. Bayes Terms
Tier 3

Explain the difference between \(P(D|\theta)\) and \(P(\theta|D)\) using a numerical example of your own. Clearly identify prior, likelihood, posterior, and evidence.

Solution

Here is a simple example. Suppose a coin model \(\theta\) represents the hypothesis “the coin is biased toward heads.” Before seeing data, suppose \(P(\theta)=0.4\). We observe data \(D\) and suppose \(P(D|\theta)=0.8\).

  • Prior: \(P(\theta)=0.4\) — belief about the parameter before seeing the data.
  • Likelihood: \(P(D|\theta)=0.8\) — how compatible the observed data are with that parameter.
  • Evidence: \(P(D)\) — overall probability of observing the data.
  • Posterior: \(P(\theta|D)\) — updated belief about the parameter after seeing the data.

The important distinction is the direction of conditioning:

\[P(D|\theta)\neq P(\theta|D).\]

The first asks “How likely is the data if the parameter is known?” The second asks “How likely is the parameter after seeing the data?”

Part H — Bayes Classifier

Q22. Bayes Classifier
Tier 2

Given \(P(+1)=0.6,P(-1)=0.4,P(x|+1)=0.2,P(x|-1)=0.5\), calculate \(P(+1|x)\), \(P(-1|x)\), and the predicted class.

Solution

Bayes' rule gives

\[P(y|x)=\frac{P(x|y)P(y)}{P(x)}.\]

The unnormalized scores are

\[+1:\;0.2(0.6)=0.12,\qquad -1:\;0.5(0.4)=0.20.\]

The denominator is

\[P(x)=0.12+0.20=0.32.\]

Therefore

\[P(+1|x)=\frac{0.12}{0.32}=\boxed{0.375},\qquad P(-1|x)=\frac{0.20}{0.32}=\boxed{0.625}.\]

The Bayes classifier chooses the larger posterior, so the prediction is \(-1\).

Q23. Unnormalized Bayes
Tier 2

Given \(P(+1)=0.3,P(-1)=0.7,P(x|+1)=0.8,P(x|-1)=0.2\): (1) calculate the two unnormalized posterior scores, (2) determine the class without calculating the denominator, and (3) explain why the denominator can be ignored for class prediction.

Solution

Compute the two unnormalized posterior scores:

\[P(x|+1)P(+1)=0.8(0.3)=\boxed{0.24},\]
\[P(x|-1)P(-1)=0.2(0.7)=\boxed{0.14}.\]

Since 0.24 > 0.14, predict \(+1\) without calculating the denominator.

The denominator \(P(x)\) is common to both classes:

\[P(+1|x)=\frac{0.24}{P(x)},\qquad P(-1|x)=\frac{0.14}{P(x)}.\]

Dividing both scores by the same positive number cannot change which score is larger, so the denominator is unnecessary for the class decision.

Q24. Bayes Error
Tier 2

For a binary problem, \(\eta(x)=P(Y=+1|X=x)=0.35\). Determine (1) \(P(Y=-1|X=x)\), (2) the Bayes-optimal class, and (3) the Bayes classification error at this \(x\).

Solution

We are given

\[\eta(x)=P(Y=+1|X=x)=0.35.\]
  1. The two class probabilities must sum to 1:
    \[P(Y=-1|X=x)=1-0.35=\boxed{0.65}.\]
  2. Because \(0.65>0.35\), the Bayes-optimal prediction is \(-1\).
  3. The probability of making an error with the Bayes decision is the smaller posterior probability:
    \[\boxed{R^*(x)=\min(0.35,0.65)=0.35}.\]

Part I — Multivariate Gaussian

Q25. Covariance Matrix
Tier 2

Two features have \(X_1=[1,2,3]\) and \(X_2=[2,4,6]\). Calculate (1) \(\mu_1,\mu_2\), (2) \(Var(X_1)\), (3) \(Var(X_2)\), (4) \(Cov(X_1,X_2)\), and (5) construct \(\Sigma\).

Solution

Using the population-style variance/covariance convention used in the lecture discussion (divide by \(n\)):

\[\mu_1=\frac{1+2+3}{3}=\boxed{2},\qquad \mu_2=\frac{2+4+6}{3}=\boxed{4}.\]

For \(X_1\), deviations are \(-1,0,1\):

\[Var(X_1)=\frac{(-1)^2+0^2+1^2}{3}=\boxed{\frac23}.\]

For \(X_2\), deviations are \(-2,0,2\):

\[Var(X_2)=\frac{4+0+4}{3}=\boxed{\frac83}.\]

The covariance is

\[Cov(X_1,X_2)=\frac{(-1)(-2)+0(0)+(1)(2)}{3}=\boxed{\frac43}.\]

Therefore

\[\boxed{\Sigma=\begin{bmatrix}\frac23&\frac43\\\frac43&\frac83\end{bmatrix}}.\]

The positive covariance means the two features increase together.

Q26. Multivariate Gaussian Numerical
Tier 2
\[\mu=\begin{bmatrix}2\\3\end{bmatrix},\qquad\Sigma=\begin{bmatrix}4&0\\0&9\end{bmatrix},\qquad x=\begin{bmatrix}4\\6\end{bmatrix}.\]

Calculate (1) \(x-\mu\), (2) \(\Sigma^{-1}\), (3) \((x-\mu)^T\Sigma^{-1}(x-\mu)\), and (4) identify what the final quantity represents.

Solution

  1. Subtract the mean:
    \[x-\mu=\begin{bmatrix}4-2\\6-3\end{bmatrix}=\boxed{\begin{bmatrix}2\\3\end{bmatrix}}.\]
  2. Because \(\Sigma\) is diagonal, invert each diagonal entry:
    \[\Sigma^{-1}=\begin{bmatrix}1/4&0\\0&1/9\end{bmatrix}.\]
  3. Calculate the covariance-adjusted squared distance:
    \[(x-\mu)^T\Sigma^{-1}(x-\mu)=\begin{bmatrix}2&3\end{bmatrix}\begin{bmatrix}1/4&0\\0&1/9\end{bmatrix}\begin{bmatrix}2\\3\end{bmatrix}=1+1=\boxed{2}.\]
  4. This is the squared Mahalanobis distance from \(x\) to the mean, adjusted for the variances and covariances encoded by \(\Sigma\).
Q27. Gaussian Classification
Tier 2

Given \(P(+1)=P(-1)=0.5\), \(p(x|+1)=0.12\), and \(p(x|-1)=0.04\), calculate the posterior probabilities and classify \(x\). Then repeat conceptually when \(P(+1)=0.2,P(-1)=0.8\).

Solution

With equal priors, the unnormalized scores are

\[+1:\;0.12(0.5)=0.06,\qquad -1:\;0.04(0.5)=0.02.\]

The denominator is \(0.08\), so

\[P(+1|x)=\frac{0.06}{0.08}=\boxed{0.75},\qquad P(-1|x)=\frac{0.02}{0.08}=\boxed{0.25}.\]

Hence classify as \(+1\).

With new priors \(P(+1)=0.2\) and \(P(-1)=0.8\), the scores become

\[+1:\;0.12(0.2)=0.024,\qquad -1:\;0.04(0.8)=0.032.\]

Now \(-1\) has the larger score, so the predicted class changes to \(-1\). This shows why class priors matter in Bayes classification.

Q28. Professor-style Logistic Question
Tier 1

A logistic regression model predicts whether a student will pass an exam.

FeatureValue
Study hours8
Attendance (%)75
Previous score70

Training statistics:

\[\mu=[6,80,65],\qquad\sigma=[2,10,5]\]

Model:

\[w=[-1.2,0.8,-0.4,0.6]^T\]

where the first element is the intercept.

  1. Standardize all three features.
  2. Construct the \(x\) vector including the intercept.
  3. Calculate \(w^Tx\).
  4. Calculate \(p(y=1|x)=\frac1{1+e^{-w^Tx}}\).
  5. Using threshold \(0.5\), classify the student.

Solution

  1. Standardize using \(x_j'=(x_j-\mu_j)/\sigma_j\):
    \[x_1'=\frac{8-6}{2}=1,\qquad x_2'=\frac{75-80}{10}=-0.5,\qquad x_3'=\frac{70-65}{5}=1.\]
  2. Include the intercept as the first entry:
    \[\boxed{x=\begin{bmatrix}1\\1\\-0.5\\1\end{bmatrix}}.\]
  3. Compute the linear score:
    \[w^Tx=(-1.2)(1)+(0.8)(1)+(-0.4)(-0.5)+(0.6)(1)=-0.2.\]
  4. Apply the sigmoid:
    \[p(y=1|x)=\frac1{1+e^{-(-0.2)}}=\frac1{1+e^{0.2}}\approx\boxed{0.4502}.\]
  5. Since \(0.4502<0.5\), predict class 0 / not pass.

Workflow to remember: standardize → add intercept → compute \(w^Tx\) → sigmoid → threshold.

Q29. Logistic Regression Probability
Tier 1
\[w=[-2,1.5,-0.5]^T,\qquad x=[1,2,3]^T.\]

Calculate (1) \(w^Tx\), (2) \(p(y=1|x)\), (3) \(p(y=0|x)\), and (4) the predicted class using threshold \(0.5\).

Solution

  1. Compute the linear score:
    \[w^Tx=(-2)(1)+(1.5)(2)+(-0.5)(3)=-2+3-1=\boxed{0}.\]
  2. Sigmoid of zero is
    \[p(y=1|x)=\frac1{1+e^0}=\boxed{0.5}.\]
  3. For binary labels \(0,1\),
    \[p(y=0|x)=1-p(y=1|x)=\boxed{0.5}.\]
  4. Using the stated threshold \(0.5\), if the rule is “predict 1 when probability \(\ge0.5\),” the prediction is 1. If a course uses a strict \(>0.5\) rule, this exact boundary point would be treated as the threshold case; state your convention.
Q30. Logistic Decision Boundary
Tier 1
\[P(Y=1|x)=\frac1{1+e^{-w^Tx}},\qquad w=[-4,2,1]^T,\qquad x=[1,x_1,x_2]^T.\]
  1. Derive the decision boundary.
  2. Express \(x_2\) as a function of \(x_1\).
  3. Determine the predicted class for \(x_1=1,x_2=3\).

Solution

  1. The sigmoid outputs 0.5 exactly when its input is zero. Therefore the decision boundary is
    \[w^Tx=0.\]
  2. Here
    \[-4+2x_1+x_2=0\]
    so
    \[\boxed{x_2=4-2x_1}.\]
  3. For \(x_1=1,x_2=3\), the score is
    \[-4+2(1)+3=1.\]
    Since the score is positive, the sigmoid probability is greater than 0.5. Therefore the predicted class is \(Y=1\).
Q31. Logistic Regression MLE
Tier 1
\[x_1=[1,1]^T,\quad y_1=+1,\qquad x_2=[1,-1]^T,\quad y_2=-1,\qquad w=[0.5,1]^T.\]

Calculate

\[P(y_i|x_i;w)=\frac1{1+\exp(-y_iw^Tx_i)}\]

for both observations. Then calculate

\[L(w)=\prod_iP(y_i|x_i;w).\]

Solution

For the first observation:

\[w^Tx_1=(0.5)(1)+(1)(1)=1.5.\]

Since \(y_1=+1\),

\[P(y_1|x_1;w)=\frac1{1+e^{-1.5}}\approx\boxed{0.8176}.\]

For the second observation:

\[w^Tx_2=(0.5)(1)+(1)(-1)=-0.5.\]

Since \(y_2=-1\), the product \(y_2w^Tx_2=(-1)(-0.5)=0.5\). Thus

\[P(y_2|x_2;w)=\frac1{1+e^{-0.5}}\approx\boxed{0.6225}.\]

The likelihood is the product:

\[L(w)=0.8176(0.6225)\approx\boxed{0.5089}.\]

MLE would choose the parameter values that maximize this likelihood over possible \(w\).

Q32. Logistic Loss / BCE
Tier 1
\[y=[1,0,1],\qquad\hat y=[0.8,0.3,0.6].\]

Calculate

\[BCE=-\sum_i\left[y_i\log\hat y_i+(1-y_i)\log(1-\hat y_i)\right].\]

Solution

Use the BCE formula term by term.

  • For \(y_1=1,\hat y_1=0.8\): contribution \(-\log(0.8)\).
  • For \(y_2=0,\hat y_2=0.3\): contribution \(-\log(1-0.3)=-\log(0.7)\).
  • For \(y_3=1,\hat y_3=0.6\): contribution \(-\log(0.6)\).
\[BCE=-\bigl[\log(0.8)+\log(0.7)+\log(0.6)\bigr].\]
\[\boxed{BCE\approx1.0906}.\]

The smaller the BCE, the better the predicted probabilities agree with the true labels.

Q33. Regression Tree Leaf
Tier 1

A leaf contains target values \([40,50,60,70]\). Find the optimal regression output \(r_l^*\) and calculate the contribution of this leaf to squared-error loss.

Solution

For squared-error regression, the optimal constant prediction in a leaf is the mean of the target values:

\[r_l^*=\frac{40+50+60+70}{4}=\boxed{55}.\]

The leaf loss is the sum of squared deviations from this mean:

\[\mathcal L_l=(40-55)^2+(50-55)^2+(60-55)^2+(70-55)^2.\]
\[=225+25+25+225=\boxed{500}.\]

The mean is optimal because, among all constant predictions \(r\), the value that minimizes \(\sum_i(y_i-r)^2\) is the arithmetic mean.

Q34. Greedy Split
Tier 1

Target values are \([10,12,20,22,30,32]\). A candidate split produces \(L=[10,12,20]\) and \(R=[22,30,32]\).

  1. Calculate \(r_L^*\).
  2. Calculate \(r_R^*\).
  3. Calculate squared-error loss of each region.
  4. Calculate total loss.
  5. Explain why the mean is used as the prediction in each leaf.

Solution

  1. Left prediction:
    \[r_L^*=\frac{10+12+20}{3}=\boxed{14}.\]
  2. Right prediction:
    \[r_R^*=\frac{22+30+32}{3}=\boxed{28}.\]
  3. Left loss:
    \[(10-14)^2+(12-14)^2+(20-14)^2=16+4+36=\boxed{56}.\]
    Right loss:
    \[(22-28)^2+(30-28)^2+(32-28)^2=36+4+16=\boxed{56}.\]
  4. Total loss:
    \[\boxed{56+56=112}.\]
  5. The mean is used because the tree predicts one constant value for every point in a leaf. Under squared-error loss, the mean is the constant that minimizes the sum of squared errors.

Q36. Full Greedy Tree
Tier 1

Using the same six-house dataset from Q35, construct the regression tree using the greedy algorithm.

  1. List the candidate splits.
  2. Calculate the resulting loss for each candidate.
  3. Select the minimum-loss split.
  4. Continue recursively until a full-depth tree is obtained.
  5. Clearly show the final tree and prediction at every leaf.

Solution

We use Size as the splitting feature, consistent with Q35. For six sorted houses, the five candidate splits are between consecutive sizes.

800 | 1000–1800485.2

800–1200 | 1400–1800196.0
800–1400 | 1600–1800149.5
800–1600 | 1800370.0

The minimum is 149.5, so the root split is after H4:

\[Size\le1400\quad\text{vs.}\quad Size>1400.\]

This gives left prices \([40,45,50,55]\), whose mean is \(47.5\), and right prices \([65,72]\), whose mean is \(68.5\).

Now split the left region. Its three candidate losses are:

Left-region splitSSE
H1 | H2,H3,H450
H1,H2 | H3,H425
H1,H2,H3 | H450

So split the left region into \(\{H1,H2\}\) and \(\{H3,H4\}\). Their predictions are

\[\frac{40+45}{2}=\boxed{42.5},\qquad \frac{50+55}{2}=\boxed{52.5}.\]

The right region \(\{H5,H6\}\) can be split into the two individual houses, giving zero SSE in each leaf and predictions 65 and 72.

  • H1 → prediction 40
  • H2 → prediction 45
  • H3 → prediction 50
  • H4 → prediction 55
  • H5 → prediction 65
  • H6 → prediction 72

Greedy rule: at each node, test candidate splits, choose the one with minimum immediate loss, then repeat the same process independently inside each child.

Q37. Post-Pruning
Tier 1

A fully grown regression tree has \(\mathcal L=20\) and \(|L(\mathcal T)|=6\). Let \(\lambda=5\). After pruning one subtree, \(\mathcal L_{\mathrm{pruned}}=27\) and \(|L(\mathcal T_{\mathrm{pruned}})|=3\).

Using

\[\mathcal L_{\mathrm{regularized}}=\mathcal L+\lambda|L(\mathcal T)|\]

calculate the regularized loss of both trees and determine whether pruning should be performed.

Solution

For the fully grown tree:

\[\mathcal L_{reg}=20+5(6)=20+30=\boxed{50}.\]

For the pruned tree:

\[\mathcal L_{reg,pruned}=27+5(3)=27+15=\boxed{42}.\]

Although pruning increases the ordinary training loss from 20 to 27, it reduces the complexity penalty much more. Since 42 < 50, the regularized objective prefers the pruned tree.

Decision: Yes, perform the pruning.
