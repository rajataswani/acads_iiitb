1. Linear Regression

Overview

Predicts a continuous numerical output by choosing parameters that minimize squared prediction error.

Formulas

\[\hat y=w_0+w_1x\]
\[\hat y=w_0+\sum_{j=1}^{d}w_jx_j\]
\[\hat y=Xw\]
\[L(w)=\sum_i(y_i-\hat y_i)^2=\|y-Xw\|^2=(y-Xw)^T(y-Xw)\]
\[X^TXw=X^Ty\]
\[\boxed{w^*=(X^TX)^{-1}X^Ty}\]
\[w_1=\frac{\sum_i(x_i-\bar x)(y_i-\bar y)}{\sum_i(x_i-\bar x)^2},\quad w_0=\bar y-w_1\]
\[\mathcal L=\frac1n(y-Xw)^T(y-Xw)\]

Numerical points

  • Put a column of 1s in \(X\) for \(w_0\).
  • Know dimensions: \(X:n\times(d+1)\), \(w:(d+1)\times1\).
  • Use the closed form when \(X^TX\) is invertible/full column rank.
  • Simple regression can use slope/intercept formulas.

2. Polynomial Regression

Overview

Adds powers of features to model curves. Nonlinear in \(x\), but linear in parameters.

Formulas

\[\hat y=w_0+w_1x+w_2x^2\]
\[\hat y=\sum_{k=0}^{d}w_kx^k\]
\[f(x;w)=\sum_{k=0}^{d}w_kh_k(x)\]
\[w^*=(X^TX)^{-1}X^Ty\]

Numerical points

  • Build columns \(1,x,x^2,\ldots,x^d\).
  • Use least squares after feature expansion.
  • Higher degree → more flexibility but greater overfitting risk.

3. Bias–Variance

Overview

Explains the trade-off between a model being too simple and too sensitive to training data.

\[y=f(x)+\epsilon\]
\[\bar{\hat f}(x)=E[\hat f(x)]\]
\[\boxed{E[(y-\hat f(x))^2]=Bias^2+Variance+\sigma^2}\]
\[Bias^2=(E[\hat f(x)]-f(x))^2\]
\[Variance=E[(\hat f(x)-E[\hat f(x)])^2]\]

Numerical/conceptual points

  • High bias → underfitting.
  • High variance → overfitting.
  • Complexity ↑ → bias tends ↓, variance tends ↑.
  • Noise is irreducible.

4. Cross Validation

Overview

Estimates generalization performance by repeatedly training and validating on different folds.

\[\text{CV error}=\frac1K\sum_{k=1}^{K}\text{ValidationError}_k\]
\[\text{LOOCV}:K=n\]

Numerical points

  • K-fold: train on \(K-1\) folds, validate on 1; repeat K times.
  • Average the validation errors.
  • The final test set is separate.

5. Regularization

Overview

Adds a penalty to discourage overly large parameters and reduce overfitting.

\[\boxed{L'=L+\lambda P(w)}\]
\[L_{L2}=\frac1n(y-Xw)^T(y-Xw)+\lambda w^Tw=L+\lambda\sum_jw_j^2\]
\[\boxed{w^*=(X^TX+\lambda I)^{-1}X^Ty}\]
\[L_{L1}=L+\lambda\sum_j|w_j|\]
\[\left|\frac{2}{n}x_j^T(y-Xw)\right|\le\lambda\]

Numerical points

  • L1=Lasso; L2=Ridge.
  • \(\lambda=0\) → OLS.
  • L1 can make coefficients exactly zero; L2 generally shrinks without exact zeros.
  • Increasing \(\lambda\) strengthens regularization.
  • For Ridge, use \(X^TX+\lambda I\).

6. Maximum Likelihood Estimation (MLE)

Overview

Chooses parameter values that make the observed data most likely under an assumed probability model.

\[y_i=f(x_i;w)+\epsilon_i\]
\[\epsilon_i\sim N(0,\sigma^2)\]
\[p(y_i|x_i,w,\sigma^2)=\frac1{\sqrt{2\pi\sigma^2}}\exp\left(-\frac{(y_i-f(x_i;w))^2}{2\sigma^2}\right)\]
\[L(w,\sigma^2)=\prod_i p(y_i|x_i,w,\sigma^2)\]
\[(w^*,\sigma^{2*})=\arg\max L(w,\sigma^2)\]
\[\log L=-\frac n2\log(2\pi)-n\log\sigma-\frac1{2\sigma^2}\sum_i(y_i-f(x_i;w))^2\]
\[w^*=(X^TX)^{-1}X^Ty\]
\[\boxed{\sigma^{2*}=\frac1n\sum_i(y_i-\hat y_i)^2}\]
\[\exp(a)=e^a\]

Numerical points

  • Decode \(x_i,y_i,w,\epsilon_i,\sigma^2\) before calculating.
  • Independent observations → multiply likelihoods.
  • Log turns products into sums and preserves the maximizer.
  • Gaussian MLE for \(w\) is equivalent to least squares.
  • After finding \(w^*\), use residuals to calculate \(\sigma^{2*}\).

7. Bayesian Approach

Overview

Combines prior belief and observed data to obtain a posterior belief about a parameter.

\[\boxed{P(\theta|D)=\frac{P(D|\theta)P(\theta)}{P(D)}}\]
\[P(\theta|D)\propto P(D|\theta)P(\theta)\]
TermMeaning
\(P(\theta|D)\)Posterior
\(P(D|\theta)\)Likelihood
\(P(\theta)\)Prior
\(P(D)\)Evidence/normalizer

Numerical points

  • Map each quantity to prior/likelihood/posterior/evidence first.
  • For relative posterior comparisons, use proportionality.
  • MLE uses data; Bayesian reasoning uses prior + data.

8. Bayes Classifier

Overview

Assigns a new input to the class with the highest posterior probability.

\[\boxed{P(Y=c|X=x)=\frac{P(X=x|Y=c)P(Y=c)}{P(X=x)}}\]
\[\eta(x)=P(Y=+1|X=x)\]
\[P(Y=-1|X=x)=1-\eta(x)\]
\[\boxed{h^*(x)=\begin{cases}+1,&\eta(x)>\frac12\\-1,&\eta(x)<\frac12\end{cases}}\]
\[\boxed{P(+1|x)=\frac{P(x|+1)P(+1)}{P(x|+1)P(+1)+P(x|-1)P(-1)}}\]

Numerical points

  • To calculate posterior, numerator = class-conditional × class prior.
  • For classification only, compare \(P(x|c)P(c)\); the denominator is common.
  • Never confuse \(P(x|c)\) with \(P(c|x)\).

9. Multivariate Gaussian

Overview

Models the distribution of multiple features jointly. In Bayes classification it supplies the class-conditional density \(P(x|y)\).

\[p(x)=\frac1{\sqrt{2\pi\sigma^2}}\exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)\]
\[\operatorname{Var}(X)=\frac1n\sum_i(x_i-\mu)^2\]
\[\sigma=\sqrt{\sigma^2}\]
\[\operatorname{Cov}(X,Y)=\frac1n\sum_i(x_i-\mu_X)(y_i-\mu_Y)\]
\[\Sigma=\begin{bmatrix}\operatorname{Var}(X_1)&\operatorname{Cov}(X_1,X_2)\\\operatorname{Cov}(X_2,X_1)&\operatorname{Var}(X_2)\end{bmatrix}\]
\[\boxed{p(x|y)=\frac1{(2\pi)^{d/2}|\Sigma|^{1/2}}\exp\left[-\frac12(x-\mu)^T\Sigma^{-1}(x-\mu)\right]}\]
\[(x-\mu)^T\Sigma^{-1}(x-\mu)\]
\[\Sigma=\begin{bmatrix}\sigma_1^2&0\\0&\sigma_2^2\end{bmatrix}\Rightarrow\frac{(x_1-\mu_1)^2}{\sigma_1^2}+\frac{(x_2-\mu_2)^2}{\sigma_2^2}\]

Numerical points

  • Diagonal of \(\Sigma\) = variances; off-diagonal = covariances.
  • Identify \(d,\mu,\Sigma,|\Sigma|,\Sigma^{-1}\).
  • Calculate the Gaussian density for each class separately.
  • Then multiply each density by its class prior for Bayes classification.

10. Logistic Regression

Overview

A binary classification method. It computes a linear score and converts it into a probability using the sigmoid function.

\[x=[1,x_1,\ldots,x_d]^T,\quad w=[w_0,w_1,\ldots,w_d]^T\]
\[z=w^Tx=w_0+w_1x_1+\cdots+w_dx_d\]
\[\boxed{\sigma(z)=\frac1{1+e^{-z}}}\]
\[\boxed{P(Y=1|x)=\sigma(w^Tx)=\frac1{1+e^{-w^Tx}}}\]
\[P(Y=0|x)=1-\sigma(w^Tx)=\frac1{1+e^{w^Tx}}\]
\[\boxed{h^*(x)=\begin{cases}1,&w^Tx>0\\0,&\text{otherwise}\end{cases}}\]
\[\boxed{w^Tx=0}\quad\text{decision boundary}
\[\boxed{\log\frac{P(+1|x)}{P(-1|x)}=w^Tx}\]

MLE / loss formulas

\[P(y_i|x_i;w)=\frac1{1+\exp(-y_iw^Tx_i)}\quad(y_i\in\{-1,+1\})\]
\[L(w)=\prod_iP(y_i|x_i;w)\]
\[\hat w=\arg\max_wL(w)\]
\[\log L=-\sum_i\log(1+e^{-y_iw^Tx_i})\]
\[-\log L=\sum_i\log(1+e^{-y_iw^Tx_i})\]
\[w_{t+1}=w_t-\eta\nabla L(w_t)\]
\[w_{t+1}=w_t+\eta\sum_i\frac{y_ix_i}{1+e^{y_iw_t^Tx_i}}\]

0/1 formulation

\[P(y_i|x_i;w)=\hat y_i^{y_i}(1-\hat y_i)^{1-y_i}\]
\[L(w)=\prod_i\hat y_i^{y_i}(1-\hat y_i)^{1-y_i}\]
\[\log L=\sum_i[y_i\log\hat y_i+(1-y_i)\log(1-\hat y_i)]\]
\[\boxed{BCE=-\sum_i[y_i\log\hat y_i+(1-y_i)\log(1-\hat y_i)]}\]

Numerical points

  • Compute \(z=w^Tx\), then sigmoid.
  • \(P>0.5\iff w^Tx>0\).
  • Likelihood multiplies examples; log-likelihood adds them.
  • BCE = negative log-likelihood for the binary 0/1 formulation.
  • No general closed-form solution like linear regression; use iterative gradient optimization.

11. Decision Trees / Regression Trees

Overview

A non-parametric method that repeatedly splits the input space. In regression, each leaf predicts a numerical value and the preferred split minimizes squared-error loss.

\[S=\{(x_1,y_1),\ldots,(x_n,y_n)\}\]
\[\mathcal X=\mathbb R^d,\quad\mathcal Y=\mathbb R\]
\[f_{\mathcal T}(x_i)=r_{l(x_i)}\]
\[\boxed{r_l^*=\arg\min_{r\in\mathbb R}\frac1n\sum_{i:x_i\in\mathcal X_l}(y_i-r)^2}\]
\[\boxed{r_l^*=\frac1{n_l}\sum_{i:x_i\in\mathcal X_l}y_i}\]
\[\boxed{\mathcal L=\frac1n\sum_{i=1}^{n}(y_i-f_{\mathcal T}(x_i))^2}\]
\[\mathcal L=\frac1n\sum_{l\in L(\mathcal T)}\sum_{i:x_i\in\mathcal X_l}(y_i-r_l^*)^2\]

Numerical procedure

  1. Choose candidate feature/threshold.
  2. Split the data.
  3. Calculate mean \(y\) in every new leaf.
  4. Calculate total MSE/loss.
  5. Choose the minimum-loss split.
  6. Repeat recursively.

Remember: The tree groups houses with similar prices. Mean = best leaf prediction under squared error. Minimum resulting loss = best split. A very deep tree can reach training loss 0 but overfit.

Stopping / overfitting

  • Minimum number of examples in a leaf.
  • Small enough target variance.
  • Restrict candidate thresholds.
  • Purpose: control complexity and improve generalization.

Classification-tree formulas (recognition only)

\[H_l=-p_l^1\log_2(p_l^1)-(1-p_l^1)\log_2(1-p_l^1)\]
\[G_l=p_l^1(1-p_l^1)\]
